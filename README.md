# WelcomeMart single-page website

## Files
- `index.html` — complete responsive single-page website.
- `assets/welcomemart-logo.jpg` — supplied WelcomeMart logo.

## Run locally
Open `index.html` in a modern browser, or serve the folder with any static web server.

## Features
- One HTML page with smooth section navigation.
- Responsive mobile navigation and product search.
- Client-side category filters.
- Sample products clearly marked as examples; prices are not invented.
- Click-to-call, WhatsApp enquiry and Google Maps directions.
- Contact form validation. The form opens WhatsApp with a prepared message; it does not claim to send anything automatically.
- SEO metadata, semantic landmarks, accessible labels, reduced-motion support.

## Before publishing
- Confirm the address, opening hours and contact numbers.
- Replace sample product cards with verified inventory and real prices if desired.
- Replace the frozen-food category image URL if it does not load; all other imagery is served from Unsplash and requires an internet connection.
- Test the WhatsApp number and Google Maps destination.
- If you need enquiries to be stored or emailed automatically, connect a real form backend or CRM.
